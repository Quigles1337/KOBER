# ADR-0000 — Bootstrap: repo location, constitution provenance, remote policy

- **Status:** accepted (Session 1, 2026-08-22)

## Context

Session 1 was invoked with the constitution supplied as session-prompt text (a paste), not as a file
on disk. A sweep of `C:\Users\LEET`, `Downloads`, `Desktop`, and `Documents` (top level,
case-insensitive `*kober*`) found no pre-existing KOBER file or directory. The invocation working
directory `C:\Users\LEET` is not a git repository; the operator's convention on this machine is one
repository per directory directly under `C:\Users\LEET` (and OneDrive stays repo-free).

## Options

1. Create the repo at `C:\Users\LEET\KOBER` (matches the machine's layout convention).
2. Block the session and ask Al where the repo should live.
3. Place it under OneDrive (ruled out: operator keeps OneDrive repo-free by standing policy).

## Choice

Option 1 — `C:\Users\LEET\KOBER`, local-only. Default branch is **`master`**, as created by this
machine's `git init` (discovered via `git symbolic-ref HEAD`, per E7 — not chosen, not assumed).

## Rationale

Reversible (a directory move if Al prefers elsewhere), unblocks Phase 0 immediately, and follows the
established machine layout. Asking first would block a bootstrap session on a trivially reversible
choice.

## Consequences

- The constitution was written **verbatim from the session prompt** to `PROGRAM/KOBER-PROGRAM.md`
  (§6 Session 1: "never edit its content in transit"). Its provenance is the paste, not a
  pre-existing file. If Al holds an original file, diff it against the committed copy and reconcile
  via ADR if they differ.
- No remote exists. Creating one is an account action → standing escalation to Al (§4.6), tracked in
  STATE.md.
  - **Resolved 2026-08-22 (Session 3):** Al created `https://github.com/Quigles1337/KOBER`
    (**public**, empty at discovery). `origin` added, `master` pushed, escalation closed.
    Visibility is Al's owner decision; content was audited pre-push (no secrets; the stored
    S-0001 PDF is CC BY-NC-ND 4.0 — non-commercial redistribution with attribution, satisfied by
    SOURCES.md). §4.6's publication escalation still governs any *announcement/packaging* (P4.3).
- **ADR-0001 remains reserved** for the Lean toolchain pin + Mathlib decision (§P0.5); do not use
  the number for anything else.
