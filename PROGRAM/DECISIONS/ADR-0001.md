# ADR-0001 — Lean toolchain pin and Mathlib decision

- **Status:** accepted (Session 2, 2026-08-22)

## Context

§P0.5 requires pinning the Lean 4 toolchain via `lean-toolchain` and deciding Mathlib yes/no,
"after checking current stable with `elan`". Discovered (2026-08-22): elan 4.2.3; installed
toolchains v4.15.0, v4.32.2, v4.33.0, v4.33.1, v4.34.0-rc1; **current upstream stable is
v4.33.1** (GitHub API, `leanprover/lean4` releases/latest). The P0.2 extraction
(`analysis/P0.2-constraint-system.md`) shows the formalization target is finite arithmetic over
an explicitly enumerated fraction domain: six constraints, 12 variables, candidate values that
are rationals with bounded denominators, and finite solution sets.

## Options

1. Pin v4.33.1 (current stable, already installed), no Mathlib.
2. Pin v4.33.1 with Mathlib (adds ℚ, `Finset`, automation — and a large dependency, long cold
   builds, and a moving target to track).
3. Pin older v4.15.0 (matches the machine's other Lean project) — no reason; KOBER is fresh.

## Choice

Option 1: **pin `leanprover/lean4:v4.33.1`; no Mathlib initially.**

## Rationale

- v4.33.1 is the current stable and is already installed (no download, immediate green build).
- The theorem targets need only finite, decidable arithmetic over explicitly enumerated
  rationals. A small hand-rolled fraction type (numerator/denominator pairs with
  cross-multiplication comparison, or scaled integers) suffices, keeps the trust base at the
  bare kernel plus the standard three axioms (E1), and keeps `lake build` fast enough to run
  every session (E9).
- Zero external deps also removes supply-chain surface from the proof artifact.

## Consequences

- `lean/lean-toolchain` = `leanprover/lean4:v4.33.1`. Upgrades only via a new ADR.
- If P1 formalization hits genuine need for Mathlib (e.g., heavy `Finset` combinatorics for the
  measure definitions), adding it is an ADR amendment, not a silent lakefile edit.
- The fraction arithmetic library becomes part of P1.1 and gets its own golden tests against
  hand computations (E: Phase-2 spirit applies to Lean helpers too).
