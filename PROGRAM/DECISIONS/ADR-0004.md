  `8a0162103b9ec957f55f05f486481f4b209d775f`).
- **Status:** **ruled by Al** (engineer of record): rulings K15 and K16 of 2026-11-22 UTC, in
  the message that launched Session 8. Both are transcribed verbatim under *Owner decisions
  recorded*. The rest of this file is the executor's implementing text. Al was shown the whole
  file before the commit, and the commit was made only on his answer "accepted".
- **Scope:**
  - the licence under which KOBER's original software and technical documentation are offered,
    from the commit that accepts this ADR onward;
  - what that licence does not cover, and what holds for that material now;
  - where the licence is stated.

  It does not amend the constitution, which names no licence for the repository: P4.3 lists
  "licensing of our artifacts" among the things it reserves to Al, and this is his ruling. E10
  governs third-party material and is unchanged. This ADR changes no CLAIM status, no reading
  set and no result, and under it nothing in `sources/` or `analysis/` is moved, removed or
  rewritten (K16).

## Context

### KOBER has carried no licence until now

The repository has been public since 2026-08-22 (ADR-0000: Al created the remote in Session 3).
From its first commit, `e3ec346`, through `8a01621` it has held no `LICENSE` file, neither
manifest has carried a `license` field (`engine/Cargo.toml` for the crate, `lean/lakefile.toml`
for the Lean package), and the README has had no licence section. No ADR and no escalation
chose a licence before K15. On 2026-11-22 UTC, before this change, the GitHub API reported the
repository's licence as `null`.

### What Al ruled and ordered

- **K15** names the licence and the Required Notice and orders this ADR, under the next free
  number. It says to follow FRIEDMAN's ADR-0005 as it stands at a named commit, so far as it
  applies to KOBER. It gives the commercial-licence contact line in Al's own words. It orders
  two statements: that KOBER has carried no licence until now, with none granted for earlier
  versions; and that SYNDEOM's D2(b) is not followed, because nothing in KOBER is separately

  2026-10-13 on NC- and ND-licensed originals, as Syndeom ADR-0003 D5 records it, with that
  ADR's line on ND licences and derived artifacts. That ruling was made for SYNDEOM, and the
